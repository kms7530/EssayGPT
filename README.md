# EssayGPT
## 개요
본 프로젝트에서는 LSTM을 이용하여 고등학생 수준의 에세이를 작문하는 모델을 만드는것이다. 이 때, 현재 자연어 처리에서 사실상 표준인 transformer 계열에서 사용중인 BPE가 적용된 Tokenizer와 프롬프트 기법이 LSTM에서 어떠한 성능을 내고, 이의 효과를 알아보는것을 초점으로 두고 진행하였다. 

## 적용된 기술과 효과
기존에 교재에서 제공되는 예제에서는 Tokenizer를 일반 공백 단위로 처리하였다. 이는 문법이 한국어에 비해 단순한 영어에는 좋은 성능을 보여주나, 한국어의 경우 조사의 활용, 어미의 다양한 변화를 포괄하기에는 부족한 성능을 보여준다. 또한 단어가 Tokenizer에 없는 경우 OOV(Out of Vocabulary)가 발생하여 입력시 사용 가능한 단어가 제한된다. 이를 해결하기 위해 BPE(Byte Pair Encoding)가 적용된 Tokenizer를 이용하였다. 
또한 모델이 작성해야하는 형식(수필, 주장문 등)과 주제를 아는 상태에서 글을 작성할 수 있도록 하기 위해 경량화된 프롬프트를 적용하였다. 이를 이용하여 모델이 주제를 이용하여 의미없는 문장이 아닌, 주제와 관련된 글을 작성하도록 학습시켰다.
